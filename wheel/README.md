# 운명의 수레바퀴 (빌드 결과)

- `index.html`: 캐릭터 버전 (구슬마다 두근두근 캐릭터)
- `text.html`: 글자 버전 (색 구슬과 이름·번호만)

이 폴더는 `tools/wheel` 을 빌드해 만든 결과입니다. 직접 고치지 말고 `tools/wheel` 에서 고친 뒤 `npm run build` 하세요.
