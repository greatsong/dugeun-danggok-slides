# 두근두근 룰렛 디자인 회의 기록 (2026-11-15)

- **선명**: 기본 해상도 '선명'(High), Pretendard 한 글꼴, 이름표를 구슬 다 그린 뒤 따로 그리기(가려짐 해결)·가운데 정렬·멀리서 볼 때 글자 줄이기, 쿨타임 고리를 얼굴 밖으로·출발 전에는 숨김, 순위표 카드(순위/이름 두 칸, 휴대폰에서 키움), 당첨 문구 한국어, 패널 대비, 경기 중 바닥글 숨김, 미니맵 테두리
- **재미**: 결승선(체크 무늬 + "결승"), 골인 링, 결승 직전 두근 박동(가장자리 분홍 .25 이하, 커트라인 구슬 링, 심장 소리), 역전 알림(슬로모션 중에만, 한 판 3번까지), 출발 도장(600ms), 당첨 카드 등장 연출, 양쪽 구석 색종이(120개), 효과음 3개(출발·박동·팡파르)와 음소거(버튼·M 키), 여러 명 결과 줄마다 차례로 등장
